# 전자책 내지 디자인 가이드라인 v1

레퍼런스: 『실전 멘트 100가지 · 원헌드레드』 34쪽 (A4, 595×842pt).
측정: PyMuPDF로 모든 글자 크기·색·좌표와 모든 도형(막대·선·박스)을 뽑아 CSS px(A4 = 794×1123)로 환산했어요.
생성기 적용: A5(560×794)로 옮길 때 위치·여백은 ×0.705(판형 비율), 글자는 '본문 크기 ÷ 16' 비율로 곱해서 위계 비율을 그대로 지켜요.

---

## 1. 원칙 6가지

1. **면은 두 가지뿐**이에요. 밝은 본문 면은 순백이 아닌 옅은 회색(#f1f1f2)이에요. 어두운 면(#0a0a0c)은 표지·차례·장 시작 밴드·마무리에만 써요.
2. **강조색은 하나**예요(#e83e6b). 선, 막대, 번호, 라벨, 칩에만 써요. 긴 글을 강조색으로 쓰지 않아요. 진한 강조(#c92a52)는 카드 제목과 작은 태그 글씨에만 써요.
3. **글꼴은 두 벌**이에요. 제목·라벨·번호·대사·카드 제목은 고딕(Noto Sans KR 700/900)이에요. 오래 읽는 본문은 명조(Noto Serif KR 400)예요. 본문 안 강조는 고딕 굵게 섞어요.
4. **회색 단계로 위계**를 만들어요. 아래 회색 단계표 9단계만 써요.
5. **왼쪽 정렬, 같은 여백**이에요. 좌우 여백 91px, 본문 폭 612px. 가운데 정렬은 표지·차례 제목·장 시작 밴드·정리 페이지 제목·핵심 문장에만 써요.
6. **구분은 선으로** 해요. 꼭지 사이는 1px 회색 선이에요. 박스는 실습 카드와 '먼저 연다' 다크 박스 두 가지뿐이에요.

## 2. 색 — 내지 색은 언제나 확정한 표지에서 나온다

생성기는 '본문 디자인 하기'를 누르면 확정한 표지 이미지를 픽셀 단위로 읽고 색 4개를 뽑아요.
생성기에서 만든 표지라면 표지 설계값을 그대로 써요.

| 표지에서 뽑는 색 | 찾는 법 | 내지에서 쓰는 곳 |
|---|---|---|
| 바탕색 | 가장 넓은 면 | 본문 종이 = 바탕색을 아주 옅게 (어두운 표지면 무채색 종이에 강조색 기운만) |
| 밝은색 | 밝은 면 중 가장 넓은 것 | 종이 색감 |
| 어두운색 | 제일 어두운 색 (보통 제목 글자) | 장 시작 밴드·차례·마무리 다크 면, 본문 글자 |
| 강조색 | 채도 높은 색 중 면적×채도가 큰 것 (선·글자처럼 작아도 잡힘) | 막대·번호·라벨·선·칩·카드 제목 |

본문 디자인 3안은 표지 색 안에서 방향만 달라요.
- **faithful**: 표지 그대로
- **calm**: 강조색 채도를 낮추고 종이를 더 밝게
- **bold**: 강조를 진하게, 다크 면도 강조색 계열로 물들임

회색 단계(메모·메타·구분선 등)는 아래 비율대로 '본문 글자색 → 종이색'을 섞어서 만들어요. 그래서 어떤 표지 색이 와도 위계가 그대로예요.

## 7. 금지
- 장 시작 밴드에 '꼭지 N개' 같은 개수 표시를 넣지 않아요. (레퍼런스의 '001 — 020'은 항목 번호 범위라서 이 책엔 해당 없음)
- 강조색을 두 개 이상 쓰지 않아요.
- 본문에 고딕을 쓰지 않아요(아주 현대적인 표지만 예외).
- 색 박스를 남발하지 않아요(박스는 카드와 '먼저 연다' 다크 박스뿐).
- 가운데 정렬 본문, 그림자, 그라데이션 배경(차례 빛 번짐 제외), 긴 줄표(—)로 본문을 장식하지 않아요.

## 8. 색 바꾸기 (본문 디자인 안마다)

각 안 아래 '색 바꾸기' 버튼을 누르면 표지 강조색을 기준으로 한 색 조합 3개가 나와요. 다시 누르면 다른 3개가 나와요(1·2·3안이 서로 다른 조합부터 시작해요).

| 조합 | 규칙 |
|---|---|
| 보색 밴드 | 강조는 표지 그대로, 다크 밴드를 강조색 반대(180°) 계열로 |
| 보색 강조 | 밴드는 표지 그대로, 강조를 반대색으로 |
| 분할 보색 | 강조 +150°, 밴드 +210° |
| 톤온톤 | 강조색 한 계열(같은 색상, 명도만 다르게) |
| 유사색 | 강조 +28°, 밴드 −20° |
| 삼각 배색 | 강조, +120° 밴드, +240° 종이 기운 |
| 무채 + 포인트 | 먹색 밴드·회색 종이 + 표지 강조색 하나 |
| 웜 뉴트럴 | 미색 종이 + 갈색 기운 밴드 |
| 쿨 뉴트럴 | 청회색 종이 + 남색 기운 밴드 |

- 고른 색은 '이대로 책 전체 디자인 하기'에 그대로 반영돼요.
- '처음 색으로 되돌리기'를 누르면 표지에서 뽑은 색으로 돌아가요.
- 색 키(종이·밴드·강조·글자)가 각 안 아래에 항상 보여요.

## 9. 안마다 고르는 버튼 (표지·본문 공통)

| 버튼 | 하는 일 | 속도 |
|---|---|---|
| 색 바꾸기 · 보색 조합 3개 | 그 안의 배치·글꼴은 그대로 두고 색만 조합 3개 제안. 누를 때마다 다른 3개 | 바로 |
| 처음 색으로 되돌리기 | 원래 색으로 | 바로 |
| AI로 이 안만 다시 생성 | 그 안 하나만 AI가 새로 설계 (나머지 두 안과 안 겹치게). 본문은 faithful/calm/bold 방향 유지 | 20초~1분 |
| AI로 3개 전부 다시 생성 | 3안을 통째로 새로 | 20초~1분 |

- 표지 색 조합에는 '명암 반전'(밝은 표지 ↔ 어두운 표지)이 하나 더 있어요.

## 10. 페이지 안전 규칙 (검수 에이전트 결과 반영, 10.15a)

- 글은 절대 잘리지 않는다: 쪽을 실제로 그려 본 뒤 넘친 블록은 다음 쪽 앞으로 보낸다. 긴 문단은 쪽 끝에서 단어 단위로 나눠 다음 쪽에서 이어 쓴다(두 줄 미만이면 통째로 넘김).
- 소제목·실습 제목이 쪽 맨 끝에 혼자 남지 않는다.
- 소제목 + 긴 문단이 남은 자리에 안 들어가면, 남은 자리가 세 줄 이상일 때 이 쪽부터 채운다(쪽 아래가 크게 비지 않게).
- 글꼴은 책에 쓰인 글자를 전부 미리 불러온 뒤 쪽을 나눈다(한글 글꼴은 글자 묶음별로 받아서, 안 그러면 나중에 글이 길어져 잘림).
- 긴 영어 단어·주소는 줄 끝에서 끊어 내린다.
- 장 시작 밴드: 제목이 길면 글자를 32→28→25→22→20으로 줄이고, 그래도 넘치면 장식을 뺀다. PART 이름은 챕터 띠에 넣지 않는다 (CHAPTER 번호와 제목만).
- 차례: 제목 줄바꿈, 오른쪽에 세 자리 쪽번호, PART가 바뀌는 곳에 PART 이름 줄. 넘치면 글자 축소 → 쪽 수를 고르게 나눠 "이어서" 표시.
- 머리글: "책 제목 · PART 1 · CHAPTER 01"만. 자르거나 말줄임표를 쓰지 않는다.
- 번호 목록 번호 칸은 고정 폭(10번 넘어가도 본문 줄이 안 흔들림).
- 작은 회색 글씨는 대비 3:1 이상.
