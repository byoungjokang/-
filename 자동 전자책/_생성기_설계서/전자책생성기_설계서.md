# 전자책 생성기 설계서 (버전 2026.10.21m 기준)

이 문서는 생성기 HTML 파일이 없을 때 Claude가 생성기를 **처음부터 다시 만들 수 있게** 쓴 설계서예요.
지금 생성기에 있는 기능, 화면, AI 지시문, 디자인 규칙을 단계별로 정리했어요.

## 0. 이 설계서로 다시 만드는 법

1. 새 Claude 대화를 열어요. 이 폴더 파일을 모두 첨부해요(스킬백업.zip 빼고).
2. 아래 **단계별 지시문**을 1단계부터 하나씩 보내요. 한 단계가 끝나면 화면에서 확인하고 다음 단계로 가요.
3. 단계마다 "부록 B의 ○○ 코드는 그대로 써라"라고 적어 뒀어요. 규칙이 들어 있는 코드라서 그대로 쓰면 지금과 똑같이 동작해요.
4. 다 만들면 **9장 검수 체크리스트**로 확인해요.

> 주의: 코드를 새로 짜는 거라 100% 같지는 않아요. 기능과 규칙은 같게 나오지만 처음엔 한두 번 고칠 수 있어요. 생성기 HTML 백업(`_디자인가이드/전자책생성기_v….html`)이 있으면 그걸로 복원하는 게 제일 확실해요.

## 1. 뼈대

- **한 파일짜리 HTML 아티팩트.** 외부 파일 없이 HTML 하나에 CSS·JS가 다 들어가요.
- **런타임 기능 두 개:** `window.claude.use("sample")`(AI 생성), `window.claude.use("downloads")`(파일 저장). 아티팩트를 올릴 때 이 두 기능을 켜요.
- **외부 라이브러리 (cdnjs, 필요할 때만 불러오기):**
  - jszip 3.10.1 (DOCX 읽기·만들기, ZIP)
  - jspdf 2.5.1 (PDF)
  - html2canvas 1.4.1 (페이지 → 이미지)
  - pdf.js 3.11.174 (PDF 원고 읽기)
  - three.js r128 (3D 책 목업. 안 되면 2D 목업으로 대신)
- **글꼴 (Google Fonts):** Black Han Sans, Noto Sans KR(400/500/700/900), Noto Serif KR(400/700/900), Do Hyeon, Jua, Gowun Batang, Nanum Myeongjo, Song Myung, IBM Plex Sans KR.
- **화면 색:** 검정 바탕 + 노랑 포인트(다크 고정).
  - 바탕 #0c0c0b, 패널 #121210, 선 #26241c, 글자 #f4ecd0, 강조 #e8c547
  - 제목 글꼴 Black Han Sans, 본문 글꼴 IBM Plex Sans KR
- **맨 위:** "EBOOK · GENERATOR 버전 ○○○○" 라벨, 제목 "전자책 생성기", 한 줄 소개.
- **AI 안 될 때 안내(gate):** 크롬·사파리에서 claude.ai 로그인 → 복사(사본 만들기) → 설정 → 기능에서 "AI 기반 아티팩트" 켜기. 진단 정보 칸과 "AI 권한 다시 요청하기" 버튼.
- **작업 자동 저장 (탭 바로 위 막대):** 3초마다 이 브라우저에 저장(입력 칸, 리서치, 목차, 원고·장별 내용, 제목·작가 확인, 표지 3안·확정 표지·표지 이미지, 본문 3안). 새로 고침하면 자동으로 불러옴. 완성본 PDF는 용량 때문에 저장 안 함(다시 만들기). 버튼: **작업 파일로 저장**(.json, 다른 PC로 옮기기), **작업 파일 불러오기**, **새로 시작**(두 번 눌러 확인).
- **탭 8개 (순서 고정):** 01 팔리는 주제 → 02 주제 리서치 → 03 목차 설계 → 04 원고 집필 → 05 표지 디자인 → 06 본문 디자인 하기 → 07 최종 결과물 → 08 상세페이지.
  - 앞 탭 결과를 다음 탭으로 넘기는 버튼이 탭마다 있어요("이 리서치로 목차·초안 뽑기 →", "이 목차로 원고 뽑기 →").
- **AI 호출 공통:** 생성 중 "멈추기" 버튼, 결과 "복사" 버튼, 실패하면 쉬운 한국어 안내(원고가 너무 길어요 등).

## 2. 팔리는 주제

- 관심 분야 17개 중 **하나만** 체크 (+ 기타 직접 입력). 분야마다 세부 분야 칩과 "쪼개기 힌트"가 나와요. → 부록 B `CATS`
- 입력: 나와의 접점(① 이미 극복했다 / ② 극복 중이다 / ③ 관심만 있다), 대상 좁히기(선택), 내 경험·강점(선택).
- "팔리는 주제 10개 생성" → 주제 카드 10개. 카드마다 시장성·대중성 점수와 근거, "검색해보기"(네이버) 버튼.
- 하단 주의 문구: 점수는 AI 추정이니 검색으로 실제 수요를 확인하라.
- 카드를 고르면 주제 리서치 탭의 "확정 주제"로 넘어가요.
- 지시문: 부록 A "1. 팔리는 주제 뽑기" (주제 쪼개기 5개의 칼: 대상·상황·결핍·결과·방법)

## 3. 주제 리서치

- 확정 주제 칸(자동 채움) + 리서치 수준 3단계:
  - 낮음: 핵심만 빠르게
  - 보통: 리서치 지도 + 전체 보고서
  - 높음: 전체 보고서 + 2차 심화·통념 검증 (AI를 두 번 부름)
- 보고서 섹션: 【리서치 지도】【사람들이 실제로 막히는 지점】【목차 재료】【걸러야 할 통념】 등. 높음은 【2차 심화 · 챕터별 근거 매핑】 추가.
- "이 리서치로 목차·초안 뽑기 →" → 목차 설계 탭에 "주제 + [주제 리서치 보고서]"를 채워 넘겨요.
- 지시문: 부록 A "2. 주제 리서치 보고서"

## 4. 목차 설계

- 입력: 확정 주제 + 리서치(자동 채움), **타깃 독자(필수**, 성별·나이·상황까지), 톤(알아서 / 반말·직설 / 존댓말·다정한 에세이 / 정리형·실용 매뉴얼 / 스토리텔링·경험담).
- 분량 하나만 체크: 40~50쪽(챕터 7~9개) / 70~80쪽(챕터 11~14개).
- "이대로 목차 뽑기" → 목차 결과(책 제목, 부제, 원씽, 분량, 챕터마다 제목 = 결론 + 주장 한 줄).
- "이 목차로 원고 뽑기 →"로 원고 집필 탭에 넘겨요.
- 아래에 "목차 대신 목차 프롬프트만 받기"(개인 AI에 줄 프롬프트).
- 지시문: 부록 A "3. 목차 설계", 프롬프트만 받기는 "(공통) 일반 탭 프롬프트 생성기" + TABS의 task

## 5. 원고 집필

두 가지 방식이 있어요: **목차로 원고 뽑기**(AI) / **직접 입력으로 만들기**(AI 없이 프롬프트 완성).

### 5-1. 목차로 원고 뽑기
- 원고 범위: 테스트(프롤로그 + 1장만) / 전체 원고(프롤로그부터 에필로그까지).
- **문체 자료 첨부** (여러 개, DOCX·PDF·TXT·MD·.skill·.zip): 종류를 눌러서 '가이드'(규칙으로 지킴) / '내 글'(말투를 따라 씀) / '내 원고'(좋은 문장은 두고 어색한 곳만 고침)로 바꿔요.
  - AI가 첨부를 분석해 **'내 문체 규칙'**을 만들고, 화면에서 보고 고칠 수 있어요(부록 A 4-2).
- 내 경험·에피소드 칸: "챕터 번호를 붙이면 그 챕터에 넣는다".
- "이대로 원고 뽑기":
  1. 목차에서 섹션 목록을 뽑아요(프롤로그·챕터·에필로그, 부록 A 4-1).
  2. 섹션마다 원고를 써요(부록 A 4-3).
  3. 섹션 사이에 `━━━━━━━━━━━━━━━━ / 섹션 제목 / ━━━━━━━━━━━━━━━━` 구분선을 넣어요.
- 저자 경험은 지어내지 않고 `[저자 경험 넣기: 어떤 경험]`으로 비워 둬요.
- 결과 아래 버튼: 다시 생성 / 파일로 저장(PDF·DOCX) / **AI 말투 다듬기**(좋은 문장은 두고 어색한 곳만, 다듬기 기록 보기, 부록 A 4-8).

### 5-1b. 장마다 AI에게 수정·도움 요청
- 원고가 나오면 결과 아래에 "AI에게 수정·도움 요청" 칸이 생겨요. 맨 위 "원고 전체" 한 줄 + 장마다 한 줄씩.
- 장마다 **고쳐 쓰기**(그 장만 요청대로 바꿈) / **조언만 받기**(원고는 그대로, 답만) 중 고르기. 원고 전체는 조언만.
- 요청 칸 + 빠른 예시 칩(더 짧게, 더 쉬운 말로, 사람 냄새 나게, 예시 하나 더, 첫 문장 더 세게, 소제목 정리, 말투 맞추기, 억지 비유 빼기).
- 고쳐 쓰기 결과는 미리보기 → "이대로 바꾸기" / "버리기", 바꾼 뒤에도 "바꾸기 전으로 되돌리기".
- "프롬프트만 복사": 같은 요청을 개인 AI에 붙여넣을 프롬프트로 복사.
- 규칙: 요청한 것만 바꾸고 좋은 문장은 둠, 저자 경험·수치 지어내지 않음, 원래 형식(■ 소제목 등) 유지, 문체 규칙·저자 문체 규칙 그대로 적용.

### 5-2. 한 챕터 깊게 쓰기 (사람 냄새 나는 원고, 추천)
1. 챕터를 골라서 질문 5개 받기 (부록 A 4-4)
2. 한 줄씩 답하기 (모르면 비워도 됨)
3. 설계도와 첫 문장 후보 5개 확인·수정 (부록 A 4-5)
4. 이 설계도로 쓰기 (부록 A 4-6) → 독자 시선으로 스스로 채점해 걸리는 문장만 고치기 (부록 A 4-7) → "원고에 넣기"

### 5-3. 직접 입력으로 만들기 (AI 없이)
- 책 유형 프리셋, 주제(원씽 한 문장), 누가, 결핍, 결과, 방법(내 무기), 문체, 분량(얇게 20~30쪽 / 보통 40~60쪽 / 두껍게 80~100쪽), 내 경험 → 완성된 집필 프롬프트를 바로 보여주고 복사.

## 6. 표지 디자인

### 6-1. 원고 연결
- **원고 첨부: DOCX·PDF·TXT·MD** 또는 붙여넣기, 또는 "원고 집필에서 가져오기".
- 어떤 원고든 장과 소제목을 알아서 나눠요 → 부록 B `readManuscriptFile`, `docxToMarked`, `pdfToMarked`, `bookParts`
  - 워드: 제목 스타일·개요 수준 → 장/소제목, 문단 일부 굵게 → `**강조**` 유지, 스타일이 없으면 글자 크기(본문의 1.4배 이상 = 장)와 굵은 짧은 줄(= 소제목)로 짐작
  - PDF: 글자 크기로 장 제목·소제목 구분, 줄바꿈된 문단은 다시 이음, 쪽마다 반복되는 머리글·쪽번호는 뺌, 글자가 그림인 PDF는 "못 읽는다"고 안내
  - 장 제목으로 보는 말: 프롤로그, 에필로그, 들어가며, 나가며, 여는/닫는 글·편지, 머리말, 맺음말, 서문, 부록, PART n, CHAPTER n, 제n장, n장, 0n
  - 원고 속 차례 페이지는 지움(차례 뒤 제목이 본문에 다시 나오는 곳부터 본문)
  - 번호 없는 섹션: 프롤로그·에필로그·여는/닫는 글·체크리스트·부록 등. 장 번호는 제목의 번호(1장 → 01)를 따르고 없으면 순서대로.
  - 첨부하면 "섹션 12개 인식 (여는 편지 / 체크리스트 / …)"처럼 바로 알려줘요.
- 표지 그림(선택): 넣으면 그림 위에 제목을 얹은 표지(photo-full / photo-top / photo-window).

### 6-2. 제목·부제·작가 확인 (표지 만들기 전 필수)
- 원고가 연결되면 바로 확인 칸이 떠요: **제목 / 부제(비워도 됨) / 작가(이름 입력 또는 "없음" 체크)**.
- 원고에서 자동으로 채움 → 부록 B `detectBookMeta` (부제 꼴 '~위한/~에게/~하는 법'은 부제로, 제목을 감싼 `<>《》「」『』""`는 뗌)
- "이대로 표지 디자인을 만들까요?" + **"네, 이대로 표지 디자인 만들기"**를 눌러야 표지가 만들어져요.
- 제목이 비면 진행 안 함. 작가 칸이 비었는데 "없음"도 아니면 둘 중 하나 하라고 안내.

### 6-3. 표지 3안
- AI가 디자인 템플릿 10선 중 3개를 서로 다르게 골라 설계(JSON) → 생성기가 직접 그려요. → 부록 A "5. 표지 디자인 3안", 부록 B `TEMPLATES`, `SPEC_RULES`, `FONTS`
- **표지 글자는 제목·부제·작가 셋만.** 키커·배지·슬로건을 넣지 않음(AI가 보내도 지움). 작가가 없으면 표지 아래는 비우고 선도 안 그림.
- 확인한 제목·부제·작가를 3안 모두에 강제로 넣음.
- 카드마다: 평면/3D 목업 전환 미리보기, 표지 PNG, 목업 PNG, **이 표지로 확정**, **색 바꾸기 · 보색 조합 3개**, **AI로 이 안만 다시 생성**.
  - 색 바꾸기: 배치·글꼴은 두고 색만. 누를 때마다 다른 3개, "처음 색으로 되돌리기". 표지에는 '명암 반전'이 추가로 있음. → 부록 B `coverSchemes`
  - 확정한 표지의 색을 바꾸면 확정 이미지도 새로 그림(저장해 둔 그림을 지우고 다시 그리기).
- 아래 버튼: "AI로 3개 전부 다시 생성", "제목·작가 고치고 표지 다시 뽑기".
- 목업 프롬프트(한국어/영어): ① 완성 목업 프롬프트(ChatGPT·제미나이용) ② 그림만 프롬프트(아무 이미지 AI) → 부록 A "5-부록".

## 7. 본문 디자인 하기

### 7-1. 색은 확정한 표지에서
- 확정 표지(또는 넣은 표지 이미지)에서 **바탕·밝은색·어두운색·강조색**을 뽑아요. 생성기에서 만든 표지면 표지 설계값을 그대로 써요. → 부록 B `paletteFromImage`, `palToColors`
- 내지 색: 종이 = 표지 바탕을 아주 옅게, 장 시작 밴드·차례·마무리 = 표지 어두운색, 강조 = 표지 강조색.
- 회색 단계(메모·구분선·머리글 등)는 글자색↔종이색을 정해진 비율로 섞어 만들어요. 어떤 표지가 와도 위계가 같아요.

### 7-2. 본문 디자인 3안
- AI는 색을 정하지 않고 **방향과 글꼴만** 정해요: faithful(표지 그대로) / calm(차분) / bold(강조 진하게). 3안은 셋을 하나씩. → 부록 A "6. 본문(내지) 디자인 3안", 부록 B `BODY_GUIDE`
- 카드마다: 실제 원고로 그린 미리보기 2쪽(장 시작 + 본문), **색 키(종이·밴드·강조·글자)**, **색 바꾸기 · 보색 조합 3개**, **AI로 이 안만 다시 생성**, **이대로 책 전체 디자인 하기**.
  - 보색 조합 9가지: 보색 밴드 / 보색 강조 / 분할 보색 / 톤온톤 / 유사색 / 삼각 배색 / 무채 + 포인트 / 웜 뉴트럴 / 쿨 뉴트럴 → 부록 B `colorSchemes`
- 아래 버튼: "AI로 3개 전부 다시 생성".

### 7-3. 내지 엔진 (책 전체 디자인)
- 규칙 전체: `내지디자인_가이드라인.md`. 코드: 부록 B ED·edTheme·edMeta·edBlocks·edBlockEl·edFooter·edBand·edChapter·edToc·edClosing·paginate.
- 판형 A5(560×794px). 레퍼런스 A4 값을 ×0.705로 옮기고 글자는 '본문 크기 ÷ 16' 비율로.
- 차례: 제목은 절대 자르지 않고 줄바꿈. 한 쪽에 안 들어가면 글자를 92%→85%→78%로 줄이고, 그래도 넘치면 '차례 (이어서)' 쪽으로 나눔. 머리글은 길면 말줄임표(…)로 줄임.
- 페이지 순서: 확정 표지 → 다크 차례 → 장마다(첫 쪽 위 39% 다크 밴드 + 본문 시작 → 본문 쪽들) → 다크 마무리.
- 장 시작 밴드: CHAPTER 01 / PROLOGUE / EPILOGUE / APPENDIX 01 라벨 → 장 제목 → 부제 → ◆ ◇ ◆. **"꼭지 N개" 같은 개수 표시는 넣지 않음.**
- 원고 → 컴포넌트:
  - `## / ### / ■` 줄 → 강조 막대 소제목 (앞에 가는 구분선, '1. …'은 번호 '01'을 위에)
  - 거리 연습·실천·요약·정리하기·미션 소제목 → 새 페이지 정리 페이지 + 흰 카드
  - `<1단계>` · STEP 1 · '1단계:' 줄 → 흰 카드
  - '정리하면… =>', “둥근 따옴표 한 줄”, `>` 인용 → 핵심 문장 박스(위아래 강조선)
  - `→` · `※` · '참고:' → 회색 메모
  - '엄마: …', '나: …', '✗ 나쁜 예', '○ 좋은 예' → 칩 + 대사
  - `**굵게**` → 고딕 굵게
- 페이지 나누기: 소제목은 다음 블록과 붙여 넘기고, 목록은 5개 이하면 통째로, 장 마지막 쪽이 4분의 1 미만이면 앞쪽에서 끌어와 균형. 정리 페이지는 새 쪽에서.
- 모든 본문 쪽 아래: 가는 선 + "책 제목 · CHAPTER 01 제목" + 세 자리 쪽번호(강조색).
- 결과: A5 PDF(쪽마다 고화질 이미지) + 전체 디자인 한 장용 작은 그림들을 같이 저장.

## 8-3. 09 광고 소재 = ebook-meta-ads 스킬 (10.19a~)

- **정본은 스킬.** `sync_metaads_skill.py generator.html <스킬 폴더>` 가 SKILL.md · hooks · formats · image-prompts · copy · checklist · results-log · ads-schema · 예시를 원본 그대로 `<script id="maSkill">` 에 싣는다. 스킬을 고치면 이 스크립트만 다시 돌린다.
