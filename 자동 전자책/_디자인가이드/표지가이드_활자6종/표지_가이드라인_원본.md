# 전자책 활자 표지 · 3D 목업

제목 · 부제 · 한 줄 후킹 · 구성(PART)만 받아서 판매용 표지를 만든다.
그림은 그리지 않는다. **색면 · 괘선 · 사각 · 활자** 넷만 쓴다. 도형·아이콘·일러스트는 아마추어 티가 난다.

## 작업 순서

**1. 최초 1회 설치**

```bash
cd <이 스킬 폴더>
npm install
```

**2. 표지 정보 파일을 만든다.** 원고 마크다운의 프론트매터를 그대로 써도 된다.

```markdown
---
title: 30대 경력단절녀
  자존감 회복 7일
subtitle: '나는 쓸모없나' 싶던 마음을 7일 만에 정리하는 법
hook: 100명 중 90명이 재취업 전에 놓치는
cover_title: 30대
  경력단절녀
  자존감 회복
cover_accent: 7일
cover_parts: 무너진 마음부터 사실로 되돌리기 | 공백기를 근거로 바꾸기 | 흔들리지 않고 첫 지원까지
author: 지은이
colors: 232B45 EE6C1F FDF3EC
---
```

| 칸 | 쓰임 | 없으면 |
|---|---|---|
| `title` | 제목 | 필수 (`cover_title` 이 있으면 생략 가능) |
| `cover_title` | 표지에 크게 쓸 줄. 들여쓴 줄이 줄바꿈 | `title` |
| `cover_accent` | 제목 아래 강조색으로 가장 크게 쓸 말 (숫자·기간이 좋다) | 생략 |
| `hook` | 제목 위 한 줄 | 생략 |
| `subtitle` | 부제 | 생략 |
| `cover_parts` | 하단 구성 `A \| B \| C` (최대 4개, 블록형은 3개) | 하단 생략 |
| `author` | 지은이 | 생략 |
| `colors` | `짙은색 강조색 옅은색` 16진수 3개 | 네이비·오렌지 |

**원고에 없는 문구를 지어 넣지 않는다.** hook·parts 는 원고 제목 줄·목차에서 가져온다.
korean-ebook 프리셋 색과 맞추려면 그 프리셋의 `deep accent tint` 를 그대로 넣는다.

**3. 만든다.**

```bash
node scripts/cover.mjs 표지.md --style all --out 결과폴더            # 여섯 시안 모두
node scripts/cover.mjs 표지.md --style 2 --mockup                    # 하나 + 3D 목업
node scripts/cover.mjs 표지.md --style 1 --pdf 본문.pdf               # 표지를 PDF 1쪽에 붙임
```

| 스타일 | 이름 | 생김새 | 어울리는 책 |
|---|---|---|---|
| 1 | 밴드형 | 짙은 바탕 + 흰 큰 제목 + 하단 옅은 띠에 PART 구성 | 실용서 기본형. 무난하고 강하다 |
| 2 | 종이형 | 밝은 종이 바탕 + 짙은 큰 제목 + 굵은 괘선 사이 번호 목록 | 에세이·심리. 차분하고 세련됐다 |
| 3 | 블록형 | 위 60% 짙은 색면에 제목, 강조색 띠, 아래 흰 바탕에 큰 강조어 + 구성 칩 | 단기 성과·방법론. 숫자 약속이 눈에 박힌다 |
| 4 | 포스터형 | 강조색 전면 + 판 폭을 꽉 채운 거대 강조어(아래가 잘림) + 흰 제목 | 광고 썸네일에서 눈에 확 걸려야 할 때 |
| 5 | 하이라이트형 | 밝은 바탕 + 짙은 제목, 강조어 아래를 강조색 사각 띠로 형광펜처럼 칠함, 구성은 번호 사각 칸 | 자기계발·실용. 친근하고 핵심이 바로 보인다 |
| 6 | 프레임형 | 짙은 바탕 + 가는 안쪽 테두리, 모두 가운데 정렬, 강조어는 외곽선 글자 | 강의·클래스형. 단정하고 권위 있다 |

**4. 결과를 눈으로 확인한다.** 글자가 판면 밖으로 나가거나, 강조어가 띠·괘선에 붙거나,
부제 마지막 줄에 한두 글자만 남지 않았는지 본다.

## 규칙

- **세로쓰기 표지는 만들지 않는다.** 사용자가 명시적으로 거절했다. 제목은 항상 가로로 쓴다.

- 판형은 6×9인치 비율(1296×1944px, 216dpi). 본문 PDF 판형과 같다.
- 제목·강조어 크기는 `fit()` 이 판면 폭에 맞춰 정한다. 손으로 크기를 박지 않는다.
- 글꼴은 `assets/fonts` 의 페이퍼로지(OFL). 설치하지 않아도 된다.

## 이 스킬이 알고 있는 함정

- **강조색이 바탕과 안 갈리면 자동으로 다른 색을 쓴다.** 기준은 대비 2.5:1.
  3:1 로 두면 종이형 바탕 위 오렌지가 탈락해 강조가 사라진다(표지 강조어는 아주 큰 글자라 2.5 면 충분히 읽힌다).
- **목업 책등 글씨는 가운데 정렬(textBaseline middle)로 둔다.** baseline 에 두면 윗부분이 앞표지에 덮여 잘린다.
- **강조어는 띠·괘선과 띄운다.** 블록형에서 강조어를 띠 바로 아래에 두면 글자 윗부분이 띠에 붙어 보인다.
- **부제는 판면 전체 폭으로 줄을 나눈다.** 좁게 나누면 마지막 줄에 한 글자("법")만 남는다.
- **프론트매터 값은 전체를 감싼 따옴표만 벗긴다.** 앞쪽 따옴표만 지우면 '나는…' 같은 부제가 깨진다.
