# 판매 페이지 템플릿 (생성기 08 상세페이지)

- 원본: 크레킷 '판매 페이지 템플릿' (official.crekit.io/kit-template) · 12섹션 · 인라인 스타일 HTML
- 생성기는 이 템플릿의 구조·스타일을 그대로 쓰고(`buildSales`), AI는 각 칸의 글·가격·가치만 JSON으로 채운다(`runSales`).

## 자동으로 (10.17b~) · 40~60대 사용자 기준
- 08 탭에 들어가면 바로 만든다. 07에서 완성본 PDF를 만들면 그때 미리 만들어 둔다. 같은 책이면 다시 만들지 않는다.
- PDF·DOCX·TXT·생성기 ZIP·표지/목업 이미지를 올리면 그걸로 바로 만든다(ZIP 안의 DOCX를 먼저, 없으면 PDF, 그림은 표지·목업 순으로 4장까지).
- AI가 원고에서 가치(타깃·고통·약속·차별점)를 찾고, 판매가·정가도 시장 기준으로 제안한다. 보너스는 원고 안에 실제로 있는 부록·체크리스트만.
- 근거가 없는 칸은 [대괄호]로 남기지 않고 섹션째 뺀다(판매자 이야기·후기·보너스). 환불은 '크레킷 딜 페이지 환불 규정을 따릅니다'.
- 결과는 휴대폰 미리보기로 바로 보이고, 'HTML 코드 복사' 버튼이 위아래 두 개. 복사가 막히면 코드 칸을 열고 전부 선택해 준다.
- '직접 고치고 싶을 때' 칸(판매가·정가·카테고리·색·보너스·후기·판매자 이야기·환불·내 프롬프트)은 접혀 있고 선택이다.

## 12섹션
1. 오픈 퀘스천 · 첫 화면은 팔지 않고 질문으로
2. 상상 · 해결된 뒤의 장면
3. 진짜 원인 · BEFORE / AFTER
4. 판매자 이야기 · 그때 → 지금 (사용자가 준 이야기만, 없으면 [대괄호]로 비워 둠)
5. 특징 + 혜택 카드
6. 궁금증 목록 · 원고에 있는 것만
7. 실제 후기 · 사용자가 넣은 후기만, 없으면 섹션 삭제
8. 두 가지 길 비교
9. 맛보기 · 원고 속 방법 하나
10. 구성과 가격 영수증 · 판매가·정가·보너스는 사용자 입력
11. FAQ · 환불은 딜 규정 그대로(사용자 입력)
12. 마무리 · 가장 깊은 혜택 + 구매 버튼 안내 (결제 버튼은 넣지 않음)

## 지키는 규칙
- 원고에 없는 방법·숫자·사례·후기는 만들지 않는다. 저자 경험을 지어내지 않는다.
- 조사(이/가, 은/는, 으로/로, 이었/였)는 엔진이 받침에 맞춰 붙인다.
- '추가 지시 · 내 프롬프트' 칸에 크레킷 프롬프트 17 같은 지시문을 붙여 넣으면 같이 따른다(위 규칙과 부딪히면 규칙이 우선).
