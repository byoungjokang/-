# 전자책 디자인 템플릿 10선 — 출판용 디자인 명세서

이 문서는 **목업 생성용 프롬프트**를 넘어, 실제 전자책 제작에 사용할 수 있도록 정리한  
**표지 · 책등 · PART 페이지 · CHAPTER 페이지 · 본문 · 인용문 · 체크리스트 · 워크시트 · 폰트 위계**까지 포함한  
**출판용 디자인 시스템 명세서**입니다.

> 사용 목적  
> 1) 전자책 표지 시안 제작  
> 2) 3D 목업 이미지 제작  
> 3) DOCX/PDF 내지 편집  
> 4) 시리즈형 전자책 브랜딩 통일  
> 5) AI 생성용 프롬프트/편집 기준서

---

# 0. 공통 제작 기준

## 0-1. 기본 판형
- 권장 판형: **A5 세로형 (148 × 210 mm)**
- 대체 가능 판형: 140 × 210 mm / 152 × 225 mm
- 기준은 A5로 통일
- 본문 여백 기준도 A5 기준으로 작성

## 0-2. 표지 작업 기준
- 표지 비율: **1 : 1.414 계열 세로형**
- 목업용 표지는 앞표지 중심
- 실제 책형 확장 시:
  - 앞표지
  - 책등
  - 뒷표지
  - 접지 안전여백 고려
- 제목은 반드시 **축소 썸네일에서도 읽혀야 함**

## 0-3. 내지 작업 기준
- 본문 폰트 기본: **Pretendard Variable**
- 제목용 폰트: 템플릿별 지정
- 기본 본문 크기: **10.8pt ~ 11.2pt**
- 기본 줄간격: **165% ~ 175%**
- 문단 간격: **6pt ~ 10pt**
- 페이지 번호: 하단 중앙 또는 바깥쪽
- 장평/자간은 과도하게 만지지 않음
- 전자책 기준으로 너무 촘촘한 편집 금지

## 0-4. 공통 타이포 위계
- 시리즈명/키커: 9pt ~ 11pt
- 부제: 11pt ~ 14pt
- 본문: 10.8pt ~ 11.2pt
- 소제목: 13pt ~ 16pt
- 챕터 번호: 14pt ~ 18pt
- 챕터 제목: 22pt ~ 32pt
- PART 제목: 28pt ~ 42pt
- 표지 제목: 28pt ~ 46pt

## 0-5. 공통 여백 기준 (A5)
- 상단: 18 mm
- 하단: 20 mm
- 안쪽: 18 mm
- 바깥쪽: 16 mm
- 챕터 오프너는 자유롭게 확장 가능
- 워크시트 페이지는 여백을 더 넓게 잡아도 좋음

## 0-6. 공통 구성 요소
모든 템플릿은 아래 구조를 기본으로 한다.

### 표지
1. 상단 키커
2. 얇은 액센트 라인
3. 메인 제목
4. 부제
5. 핵심 비주얼
6. 하단 룰
7. 저자명

### 책등
1. 시리즈명 또는 심볼
2. 세로 제목
3. 저자명
4. 작은 브랜드 마크

### 내지
1. 속표지
2. 목차
3. PART 오프너
4. CHAPTER 오프너
5. 본문
6. 인용문/강조문
7. 체크리스트/워크시트
8. 에필로그/저자소개

## 0-7. 공통 문단 스타일 명세
- 본문 정렬: 왼쪽 정렬 또는 양끝정렬
- 문단 첫 줄 들여쓰기: 0 또는 1자, 책 성격에 따라 선택
- 강조문: 볼드 또는 액센트 컬러
- 인용문: 본문보다 130~160% 크게
- 체크리스트: 앞에 `✓` 또는 `□`
- 단계형 콘텐츠: 1단계 / 2단계 / 3단계 라벨 강조
- 질문형 문장: 배경 박스 또는 좌측 라인 처리

## 0-8. 3D 목업 공통 규칙
- 하드커버 스타일
- 앞표지 + 왼쪽 책등이 보이는 3/4 시점
- 깨끗한 화이트 또는 아주 연한 배경
- 접지 그림자 필수
- 표지 왜곡 최소화
- 과한 광택 금지
- 고급 매트 코팅 질감
- 책 두께는 중간 정도로 자연스럽게

## 01. 아이보리 라인 (IVORY LINE)

### 카테고리
경제 · 재테크 / 미니멀 · 아이보리

### 컬러 시스템
- 표지 배경: `#F3EFE7`
- 책등: `#E1D8C4`
- 내지지: `#FBF8F2`
- 잉크: `#2B2621`
- 액센트: `#B5493B`

### 폰트 시스템
- 표지 제목: **Noto Serif KR Bold / Black**
- PART / CHAPTER 제목: **Noto Serif KR Bold**
- 본문: **Pretendard Variable Regular**
- 강조문: **Pretendard SemiBold**
- 숫자/배지: **Pretendard Bold**

### 표지 타이포 규격
- 상단 키커: 10pt, 자간 +80
- 메인 제목: 34~42pt
- 부제: 13pt
- 저자명: 11pt
- 제목 줄 수: 2줄 권장
- 제목 줄간격: 105%~112%

### 표지 비주얼
- 유리 모래시계 1개
- 중앙 하단 배치
- 배경은 비우고 여백 강조
- 레드 액센트는 텍스트 또는 얇은 선에만 제한적으로 사용

### 책등
- 제목 세로 배치
- 세로 제목 크기: 15~18pt
- 저자명: 9~10pt
- 하단에 작은 다이아 또는 라인 심볼

### 내지 명세
#### PART 페이지
- PART 넘버: 20pt Pretendard Bold
- PART 제목: 30pt Noto Serif KR Bold
- 배경: `#FBF8F2`
- 액센트 라인: `#B5493B`

#### CHAPTER 페이지
- 배지 원형 직경: 14~18 mm
- 번호: 12~14pt
- 제목: 24~28pt
- 인트로 문장: 11pt

#### 본문
- 본문: 11pt
- 줄간격: 170%
- 문단 간격: 8pt

#### 인용문
- 15pt Noto Serif KR
- 좌측 붉은 세로선 2pt

#### 체크리스트
- `✓` 액센트 컬러
- 옅은 배경 박스 또는 선형 리스트

### 추천 주제
- 돈 관리
- 시간 관리
- 재테크 습관
- 미니멀 생산성

### 금지 요소
- 화려한 3D 그래픽
- 금속성 효과 남발
- 비주얼 과밀

## 08. 라인 화이트 (LINE WHITE)

### 카테고리

### 컬러 시스템
- 표지 배경: `#FFFFFF`

- 내지지: `#FFFFFF`
- 잉크: `#1A1A1A`
- 액센트: `#E23E31`

### 폰트 시스템
- 제목: **Pretendard Black**
- 본문: **Pretendard Variable**
- 포인트 문장: **Pretendard Bold**

### 표지 타이포 규격
- 제목: 34~44pt
- 부제: 12pt
- 키커: 9pt

### 표지 비주얼
- 빨간 선 하나
- 선이 흘러가며 하트나 연결 구조 형성
- 극미니멀

### 책등
- 라이트 그레이
- 블랙 제목
- 레드 라인 심볼

### 내지 명세

- 대형 숫자 사용 가능

#### CHAPTER 페이지
- 레드 배지
- 제목: 24~28pt

#### 본문
- 10.8~11pt
- 줄간격 165~170%

#### 비교 섹션
- “잘못된 말 / 바꾼 말” 구성에 적합
- 라인 박스 또는 2단 비교표 사용

### 추천 주제
- 대화법
- 관계개선
- 연애 심리
- 말투 교정

### 금지 요소
- 많은 사진
- 복잡한 일러스트
- 다색 구성

# 2. 실제 편집용 스타일 네이밍 규칙

문서 편집 시 아래 스타일명을 권장한다.

- `cover-kicker`
- `cover-title`
- `cover-subtitle`
- `cover-author`
- `part-number`
- `part-title`
- `chapter-number`
- `chapter-title`
- `chapter-intro`
- `body-text`
- `body-emphasis`
- `quote-large`
- `quote-inline`
- `checklist-item`
- `worksheet-title`
- `worksheet-box`
- `caption-text`
- `page-number`

이름을 고정하면 DOCX, 인디자인, HTML/CSS, 노션 문서에서도 일관성 유지가 쉽다.

# 4. 통합 생성/의뢰용 프롬프트 템플릿

```text
다음 전자책 정보를 바탕으로
표지, 책등, 3D 목업, PART 페이지, CHAPTER 오프너, 본문 타이포 시스템까지 포함한
프리미엄 전자책 디자인 시스템을 만든다.

[전자책 정보]
시리즈명: {시리즈명}
제목: {제목}
부제: {부제}
저자명: {저자명}
카테고리: {카테고리}
핵심 키워드: {키워드}

[적용 템플릿]
{템플릿명}

[컬러]
표지 배경: {hex}
책등: {hex}
내지지: {hex}
잉크: {hex}
액센트: {hex}

[타이포 시스템]
표지 제목 폰트: {제목폰트}
본문 폰트: Pretendard Variable

[표지 구성]
상단 키커 + 얇은 액센트 라인 + 메인 제목 2~3줄 + 부제 + 핵심 비주얼 + 하단 룰 + 저자명.

[책등 구성]
세로 제목 + 저자명 + 작은 심볼.

[내지 구성]
PART 오프너 / CHAPTER 오프너 / 본문 / 인용문 / 체크리스트 / 워크시트 스타일을 통일감 있게 설계한다.

[목업 규칙]
흰 스튜디오 배경, 왼쪽 책등이 보이는 3/4 시점, 프리미엄 하드커버, 자연스러운 그림자, 과한 왜곡 금지.
```
