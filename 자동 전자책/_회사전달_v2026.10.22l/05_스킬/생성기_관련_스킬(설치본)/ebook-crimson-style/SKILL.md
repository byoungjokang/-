# 전자책 크림슨 스타일 가이드

레퍼런스 이미지(assets/) 6장을 픽셀 단위로 색상 추출해서 만든 정확한 스타일 가이드다.
**감으로 비슷한 빨강을 쓰지 말고, 아래 헥스값을 그대로 쓴다.**

## 색상 팔레트

| 역할 | 색상 | 용도 |
|---|---|---|
| Primary Red | `#A82C22` | 표지 · 차례 · 마무리 페이지 배경 |
| Deep Red | `#7E1D17` | 장간지(챕터 도입) 배경 — 본책보다 한 톤 어둡게, 장 전환감을 줌 |
| Ivory | `#FAF5EF` | 본문 페이지 배경 / 레드 배경 위 메인 타이틀·저자명 텍스트(100%) |
| Box Beige | `#F4E7E0` | 본문 내 정의·요약 박스 배경 |
| Charcoal | `#1C1614` | 본문 헤딩 · 바디 텍스트 (순검정 아님, 따뜻한 다크브라운) |
| Accent Red | `#A82C22` | 본문 위 하위 소제목 / 박스 제목 / 인용 세로선 · 인용문 텍스트 (Primary Red와 동일 색을 크림 배경 위에 그대로 사용) |

**골드는 쓰지 않는다.** (기존 ebookmake 디자인과 가장 큰 차이점 — 이 템플릿은 레드+아이보리+차콜 3색 체계다.)

## 레드 배경 위 텍스트는 "아이보리 불투명도"로 계층을 나눈다

레드 배경(표지/차례/마무리) 위의 모든 텍스트는 검정이나 별도 회색이 아니라, **아이보리(#FAF5EF)를 불투명도만 다르게 얹은 것**이다. 이 규칙 하나로 전체 위계가 정리된다.

| 불투명도 | 용도 |
|---|---|
| 100% | 책 제목, 장 제목(장간지), 지은이명 — 가장 중요한 텍스트 |
| 40~45% | 부제, 장 요약 설명, 장간지의 짧은 구분선 |
| ~22% | 시리즈·브랜드 라벨, CONTENTS 라벨, 챕터 넘버 아웃라인(01/02...), 차례의 얇은 가로 구분선, 페이지 번호 |

장간지 배경(`#7E1D17`)에서도 같은 원리이되, 짧은 구분선만 예외적으로 43%로 좀 더 진하게 들어간다.

## 페이지별 스펙

### 1. 표지
- 배경 `#A82C22` 전면(여백 없는 풀블리드)
- 좌하단 정렬 구조 (텍스트 블록이 페이지 하단 1/3 지점에서 시작)
- 순서: `[시리즈·브랜드]` 라벨(22%) → 책 제목(100%, 큰 사이즈 2줄까지) → 얇은 가로선(짧게, 40% 근처) → 부제 1줄(40~45%) → 여백 → `[지은이]`(100%)

### 2. 차례
- 배경 `#A82C22`
- 상단 좌측: `CONTENTS` 라벨(22%, 자간 넓게) → `차례` 큰 타이틀(100%)
- `CHAPTER 01` 같은 섹션 라벨(22%)로 챕터 묶음 구분
- 각 항목: 왼쪽에 큰 아웃라인 숫자(01, 02.../ 22%) + 중앙에 소제목(100%) + 오른쪽에 페이지 번호(22%)
- 항목 사이는 얇은 가로 구분선(22%)으로만 나눔 — 박스나 배경색 대비 없음

### 3. 장간지 (챕터 도입부)
- 배경 `#7E1D17` (본책보다 어두운 톤 — 반드시 구분해서 쓴다)
- 좌하단 정렬: 큰 챕터 숫자(100%, 아웃라인 스타일) → 짧은 가로선(43%) → 장 제목 2줄까지(100%) → 한 줄 요약(40~45%)

### 4. 본문 (기본)
- 배경 `#FAF5EF`
- 챕터 숫자 아웃라인(작게, Accent Red 옅은 톤) → 소제목 2줄까지(Charcoal 100%) → 리드 문단(Charcoal ~54% 불투명도, 살짝 크게) → 빈 줄 대신 여백으로 문단 구분 → 하위 소제목(Accent Red `#A82C22` 100%, 볼드) → 본문 단락(Charcoal 진하게, 거의 100%)
- 하단: 왼쪽에 장 제목(회색조, 옅게) / 오른쪽에 페이지 번호(Accent Red)

### 5. 본문 — 박스/인용 변형
- 정의·요약 박스: 배경 `#F4E7E0`, 테두리 없음, **모서리만 둥글게, 옅은 면으로만 구분** — 절대 테두리선을 두르지 않는다
  - 박스 제목: Accent Red `#A82C22`, 볼드
  - 박스 본문: Charcoal
- 인용문: 박스 없이 **왼쪽 세로선 하나(Accent Red `#A82C22`)로만 구분**, 따옴표 안 씀
  - 인용 텍스트: Accent Red `#A82C22`
  - 출처: 그 아래 작게, Charcoal 옅게

### 6. 마무리(클로징)
- 배경 `#A82C22`, 텍스트 전부 중앙 정렬
- 페이지 정중앙 부근에 마지막 문장 1~2줄(100%) → 그 아래 지은이명(작게, 40~45%)

## 여백 · 그리드

- A4(210×297mm) 기준, 좌우 여백 각 **2cm** 균등
- 본문 페이지 하단 푸터는 여백 안쪽 가장자리에 고정(장 제목 좌 / 페이지 번호 우)
- 표지·마무리는 풀블리드(여백 없음), 텍스트 블록만 2cm 안쪽에서 시작

## 타이포그래피

- 산세리프 계열 (프리텐다드 또는 유사 고딕 권장 — 원본 폰트 파일이 없으면 이걸로 대체)
- 챕터 아웃라인 숫자만 **가는 굵기(Thin/Light)**, 나머지 제목류는 볼드
- 본문 단락은 3~5줄 단위로 끊고, 문단 사이는 **빈 줄이 아니라 여백(space-after)**으로 벌린다 (ebookmake 집필 규칙과 동일)

## 실제로 만들 때

이 스타일은 build_ebook.js 파이프라인(ebookmake 스킬)이 아니라 **docx 스킬로 직접** 만든다. 위 색상표를 그대로 python-docx의 `RGBColor`와 도형/텍스트박스 배경색에 대입하면 된다. `assets/`에 원본 레퍼런스 6장이 있으니, 색상값이 헷갈리면 다시 열어서 눈으로 대조한다.

원고 톤·집필 규칙(서술형, 1인칭, 챕터 뼈대 등)은 이 스킬이 아니라 **ebookmake 스킬**을 따른다 — 이 스킬은 순수하게 비주얼 디자인만 담당한다.
