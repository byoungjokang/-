# 광고 형식 12종 (1080x1350, 피드 4:5)

공통 캔버스: 1080x1350. 위 120px·아래 120px 안에는 잘려도 되는 것만(인스타 UI). 글자는 좌우 60px 안쪽.
공통 폰트: Noto Sans KR 900(제목) / 500(본문), 손글씨는 Nanum Pen Script. 강조색 = 팔레트 accent(밝게: 노랑 #ffcf5a, 빨강 #ff2a2a 계열).
빌더 type 이름은 괄호 안. 성과는 실제 집행 결과(results-log.md).

## A. 인물형 (사진 + 큰 문구) — 묶음의 절반 이상

### A1 결핍 인물 포스터 (`poster`)  ★ 리치코드 신규 중 채택률 최고
- 구성: 전면 사진(세로 2:3 생성, cover) → 위 50% 어두운 그라데이션 → 작은 줄(28~30px, 예 "7년 전의 저도 그랬습니다") → 제목 3줄(88~92px, 2줄째 강조) → 왼쪽 아래 책 목업(300px, -6deg) → 하단 꽉 찬 버튼(106px 높이, "{책} 확인하기 ›").
- 사진: 결핍 당사자. 돈·관계에 무너진 표정, 저채도 차가운 톤 + 얼굴에 따뜻한 조명 하나.
- 쓰는 후킹: H3 H5 H7 H8 H4.

### A2 매력 인물 포스터 (`poster`, 대화법 여자 주인공)  ★ 대화법 레퍼런스형
- 구성: A1 과 같고 사진만 다르다. 붉은 바 조명, 카메라를 보는 글래머러스한 30세 전후 여성, 오른쪽 배치, 위·왼쪽 비움.
- 밝기: 인물 쪽 `brightness(1.2~1.65)`. 사용자가 "여자 쪽 어둡다"고 했던 이력 있음 → 기본 1.35.
- 쓰는 후킹: H2 H4 H1(여자가 판정하는 말).
- 심의: 가슴골이 크게 보이면 예비로. 첫 업로드는 노출 적은 컷.

### A3 영화 자막형 (`film`)  ★ "다들 잘 사는데 나만 왜" 채택
- 구성: 위 검은 띠 300px(작은 줄 + 제목 2줄, 2줄째 강조 72px) → 가운데 스틸컷 720px(가로 3:2 생성) → 스틸 하단에 흰 자막 44px(검은 외곽 그림자, 따옴표 대사) → 아래 검은 띠 270px(책 150px + 한 줄 요약 + 버튼).
- 사진: 드라마 한 장면(편의점 결제 거절, 마트에서 고기 내려놓기, 옥탑 통화, 카페에서 눈 피하기).
- 쓰는 후킹: 제목 = 상황 설명, 자막 = H6 속마음.

### A4 휴먼다큐 속마음형 (`doc`)  ★ 5개 채택
- 구성: 위 검은 띠 280px(노란 테두리 라벨 "돈 때문에 잠 못 드는 사람들" + 제목 "누구에게도 못 했던 속마음") → 인터뷰 스틸 760px → 왼쪽 아래 이름표(노란 칸 "속마음" + 흰 칸 "32세 · 직장인") → 자막 2줄(50px, 2줄째 노랑) → 아래 띠(책 + "7년 전의 저도 그랬습니다" + 버튼).
- 사진: 방 안에서 화면 밖 인터뷰어를 보며 말하는 사람, 젖은 눈, 자연광.
- **규칙: 책 효과를 말하지 않는다. 결핍 속마음만. '재연' 표시는 넣지 않는다(사용자 결정). 실명 금지, 나이·직업만.**
- 쓰는 후킹: H6.

## B. 폰·앱 화면형 (광고 티 안 나는 캡처) — 묶음의 20~30%

### B1 카톡 대화 (`kakao`)  ★ 대화법 C 판매 1위(구매 21,860원/건), E 클릭률 8.65%
- 구성: 카톡 배경 #b2c7d9 + 노란 말풍선(내 말)·흰 말풍선(상대) + 날짜 띠 → 하단 검은 블록 480~520px(제목 2줄 + 한 줄).
- 주의: 마지막 말풍선이 검은 블록에 가리지 않게(사용자 지적 이력). 말풍선 영역은 위 780px 안.

### B2 잠금화면 알림 (`lock`)  예: 급여 입금→카드대금 출금, "좋은 인연 만나실 거예요"
- 구성: 날짜·큰 시계(200~230px) → 알림 카드 1~2개 → 큰 문구는 알림 **바로 아래**(top 800px 근처, 너무 아래 두지 말 것: 사용자 지적 이력).

### B3 DM 단답 (`dm`): 내 긴 메시지 vs 상대 "ㅋㅋ" "네". 문구 "답장 총 2글자."
### B4 검색창 자동완성 (`search`): 네이버 초록 테두리 + 자동완성 4~5줄. "이걸 검색해봤다면, ~"
### B5 메모장 (`memo`): 질문 리스트·새해 목표가 매년 복사됨(취소선). "매년 같은 목표를 복사하는 사람"
### B6 시청 기록 (`history`): 부자 습관·확언 영상 4개 시청 완료. "부자 영상만 3년째 보는 사람"

## C. 기타 (묶음에 1~3개)
### C1 퀴즈·시험지 (`quiz`): 문제 1 + 보기 4개 + 정답 빨간 동그라미(타원 width ≈ 글자폭+60). "정답은 ④ 배운 적이 없다"
### C2 실제 후기 카드 (`review`): ★5 + 후기 원문 큰 글씨 + "30대 직장인, 서울 (실제 구매 후기)". **실제 후기만**.
### C3 스토리 3장 (`story`, 9:16 1080x1920): 바닥(어둠, 문틈 빛) → 몸부림·발견(마지막 줄 "모든 문제의 근원은..." 끊기) → 답(밝은 빛 + 깨끗한 표지 + "{책} 더 알아보기"). 글자는 위 14%·아래 20% 비움. 리치코드 판매 1위 영상의 원형.

## 안 팔린 형식 (만들지 않는다)
- 책 목업이 주인공 + 문구 3줄(대화법 책목업 4종: 6만 원, 0건 / 리치코드 표지형 0건)
- 빙산 10/90 같은 도표형, 가계부·달력·계산기 같은 "숫자 화면"만 있는 형식(사용자 평가: 약함)
- 사람 없는 타이포만 있는 형식은 2개 이하로
