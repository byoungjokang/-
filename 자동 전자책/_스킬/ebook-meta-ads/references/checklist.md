# 소재 검수표 (시트를 보여주기 전에 전부 통과)

## 레이아웃
- [ ] 큰 문구가 얼굴·말풍선·책을 가리지 않는다 (가린 이력: 카톡 마지막 말풍선, 퀴즈 도장, 어두운 방 빛줄기)
- [ ] 큰 문구는 3줄 이내, 강조색 한 덩어리
- [ ] 인물 얼굴이 충분히 밝다 (어둡다는 지적 이력 → poster 기본 brightness 1.35, 필요시 1.65)
- [ ] 책 목업은 구석에 작게(300px 안팎), 주인공이 아니다
- [ ] 아래 버튼 문구가 묶음 전체에서 같다
- [ ] 1080x1350(스토리는 1080x1920), 글자 좌우 60px 안쪽
- [ ] 자막·이름표가 사진 속 장면과 맞는다 (예: "차에서 못 내려요"인데 가게 안 사진 → 자막 수정)

## 카피
- [ ] 2인칭 단정 없음 / 수익 약속 없음 / 성적 표현 없음
- [ ] 저자 수식이 intake 사실과 같다 ('27년 모솔' 류 없음)
- [ ] 실제 후기 카드는 실제 원문 그대로, 임시 후기 사용 없음
- [ ] 인물 소재가 책 효과를 말하지 않는다(가짜 후기 금지)

## 심의 위험 표시 (시트 전달 시 번호로 알림)
- 높음: 가슴골·노출이 큰 인물 → 첫 업로드 제외, 예비
- 중간: 민감 단어(PUA 등) 포함 → 묶음에 1~2개만
- 낮음: 나머지

## 사용자 선호 (이력)
- "약하다"고 한 것: 숫자 화면만 있는 형식(가계부·달력·계산기·빙산 도표), 사람 없는 타이포
- 좋아한 것: 사람이 나오는 결핍 장면, 영화 자막, 휴먼다큐 속마음, 강한 구어체 후킹("읽씹도 대답입니다ㅋㅋ", "남자로 탈락이라는 대답")
- 원하지 않은 것: '재연' 표기, 가짜 후기 느낌
