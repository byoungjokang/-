# 디자인 가이드 — 토큰, 주제별 팔레트, 컴포넌트, 금지, 검수

## 1. 토큰 체계 (바뀌지 않는 뼈대)

리치코드는 **어두운 바탕 3단 + 액센트 1색 + 글자 3단**으로만 칠해져 있다. 주제가 바뀌면 이 값만 바꾼다.

```css
:root{
  --bg:#0b0916;        /* 바탕 */
  --bg-2:#110d20;      /* 가격 카드·deep 면의 안쪽 */
  --bg-3:#191431;      /* 카드·체크 버튼·조언 박스 */
  --deep:rgba(17,13,32,.82);   /* .sec.deep 배경 (bg-2 를 82% 로) */
  --line:rgba(236,232,255,.09);
  --line-2:rgba(236,232,255,.18);
  --text:#f3f1f8;      /* 제목·강조 */
  --text-2:rgba(243,241,248,.72);  /* 본문 */
  --text-3:rgba(243,241,248,.48);  /* 캡션·흐린 글자 */
  --accent:#d4a017;    /* 버튼·배지·선·체크 */
  --accent-hi:#e8bb3a; /* 액센트 글자 (밝은 버전) */
  --accent-soft:rgba(212,160,23,.12);  /* 체크된 버튼·ignore 박스 */
  --accent-ink:#140f24;/* 액센트 위의 글자색 */
  --glow:rgba(109,64,214,.22);  /* 가격 섹션 뒤 라디얼 (팔레트의 2차 톤) */
  --topbar:#2a1760;    /* 상단 바 */
}
```

규칙
- 액센트는 **글자·얇은 선·버튼·배지·체크 표시·목차 불릿**에만. 큰 면을 액센트로 칠하지 않는다. 예외 둘: 비율 막대의 큰 쪽, 차이 섹션 첫 카드의 20% 그라데이션.
- `--glow` 는 가격 섹션 뒤 라디얼 하나에만. 다른 섹션에 글로우를 넣지 않는다.
- 순검정(#000)·순백(#fff) 금지. 바탕은 색이 있는 어두운 톤, 글자는 살짝 색이 도는 밝은 톤.
- 배경 점 패턴(별빛)은 리치코드 전용 장식. 다른 주제는 `--dots:0` 으로 끈다 (빌더 옵션).

## 2. 주제별 팔레트 선택

세 개의 실제 페이지가 각각 하나씩 증명했다: 리치코드(미드나잇 + 골드), 대화법(블랙 + 레드), ADHD(차콜 + 라임). 전부 **어두운 바탕 + 액센트 1색**이다. 어두운 12종(2-1)과 밝은 6종(2-3) 중에서 고른다. 값은 `palettes.json` 이 정본이다.

고르는 법
1. 전자책 프리셋(EB)이 있으면 2-2 표부터. 없으면 위 표의 카테고리로.
2. 광고 소재가 이미 돌고 있으면 **광고와 같은 계열**을 고른다(광고 → 페이지 색 연결).
3. 타깃이 여성·감성 쪽이면 plum-coral / wine-rose / espresso-cream 중에서, 남성·실행 쪽이면 black-red / charcoal-lime / navy-sky 중에서.
4. 둘 사이에서 고민되면 **액센트가 글자로 읽히는 쪽**(밝기 대비 큰 쪽)을 고른다. 액센트는 본문 위에 글자로 올라가야 한다.

### 2-3. 밝은 바탕 팔레트 6종

전자책 내지 템플릿(아이보리 라인·파우더 블루·블러시 소프트·세이지 그린·페이퍼 아카데믹·라인 화이트)과 같은 색으로 상세페이지를 밝게 찍을 때 쓴다. 책 표지가 밝고 부드러운 톤이거나 타깃이 여성·부모·치유 쪽일 때 고른다. 어두운 팔레트와 토큰 구조는 같고(bg 3단 + accent + text 3단) 빌더가 `body.light` 를 붙여 그림자·선만 보정한다.

밝은 바탕 규칙
- 액센트 글자는 `accentHi` 가 **더 어두운** 쪽이다(밝은 바탕 위에서 읽히도록). 어두운 팔레트와 반대.
- 카드(bg-3)는 흰색, deep 섹션은 바탕보다 한 단계 짙은 톤. 섹션 리듬은 같다.
- 그림자는 표지 drop-shadow 하나(22%)와 카드 아래 1px 뿐. 글로우는 가격 뒤 하나.
- 상단 바는 잉크색(글자색에 가까운 어두운 색)에 흰 글자.
- 선택 기준: 전자책을 밝은 템플릿으로 만들었으면 상세페이지도 그 짝으로. 광고 소재가 어두우면 어두운 팔레트를 유지한다(광고 → 페이지 색 연결이 우선).

## 4. 모션 (셋뿐)
1. 등장: `.rv` 요소가 뷰포트에 들어오면 26px 아래에서 0.9s 올라옴 (IntersectionObserver, threshold .12). 섹션 제목·카드·본문 블록에 붙인다.
2. 히어로: brand → h1 → story → actions 순서로 0.08/0.3/0.45s 지연, 표지는 0.5s 뒤 36px 상승.
3. 비율 막대 scaleX, 체크 버튼 토글, 카운트다운 50ms 갱신.
`prefers-reduced-motion: reduce` 면 전부 끈다. 마키·펄스·타이프라이터 같은 무한 모션은 캡처 슬라이드(모듈 B) 하나만 허용.

## 5. 금지 요소 (CLAUDE.md 디자인 규칙 + 리치코드에서 확인된 것)
- 형광펜 강조, 영문 대문자 eyebrow, 글로우·그라데이션 카드(차이 첫 칸 20% 예외), 번호 동그라미, 버튼 안 →, 가운뎃점 나열, 이모지, em-dash
- 세리프를 h1 밖에 쓰는 것, Inter·나눔체 같은 다른 본문 서체
- 액센트 2색, 보라 네온 글로우(리치코드의 glow 는 가격 뒤 하나뿐)
- 같은 크기 카드 3개 가로 나열, 모든 섹션 가운데 정렬(가운데는 정직 선언·가격 카드 안·중간 CTA 만)
- 가짜 숫자·가짜 스크린샷, "자정" 표기, 둥근 모서리 혼용 (임시 후기는 sample:true 표시 조건으로 허용)
- 히어로에 신뢰 띠·가격·기능 목록, 섹션 번호 라벨("01 / INDEX")

## 6. 눈 검수 체크리스트 (모바일 400px 전체 미리보기로)
