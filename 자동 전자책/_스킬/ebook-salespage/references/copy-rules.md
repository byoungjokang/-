# 카피 규칙 — 슬롯을 채울 때

## 1. 원칙 다섯
1. **사실만.** 숫자·성과·연구는 `00_intake` / `02_market` / `02_research` / 사용자가 준 것만. 없으면 `【 】` 자리표시자. 자리표시자를 그럴듯한 말로 채워 넣지 않는다. **후기만 예외**: 실제 후기가 없으면 임시 후기 6개를 써서 자리를 채우되 `sample:true` 로 표시하고, 발행 전에 실제 후기로 바꾼다.
2. **광고 첫 줄 = 히어로 첫 줄.** 메타 광고 소재가 있으면 그 첫 문장이 h1 이다. 광고를 누르고 들어온 사람이 다른 문장을 보면 이탈한다.
3. **장면으로 시작, 원리로 설명, 숫자로 닫는다.** 히어로·저자 이야기는 장면(언제·어디·무엇). 진짜 이유는 원리 하나. 목차·가격은 숫자.
4. **한 섹션 = 한 메시지.** h2 가 그 메시지다. 본문은 h2 를 설명하는 3문단 이내.
5. **독자를 단정하지 않는다.** "당신은 ~한 사람입니다" 대신 행동 묘사("월급 받자마자 카드값부터 걱정한다"). 메타 광고 정책(2인칭 단정·성적 암시)과 같은 선.

## 2. 자리표시자
- 형식: `【이미지 URL】`, `【후기 1 원문】`, `【정가】`, `【수강생 성과 캡처】`.
- 빌더 `--check` 가 개수를 센다. 전달할 때 "사용자가 채울 것" 목록으로 뽑는다.
- 이미지가 없는 figure 는 자리표시자 대신 **요소를 뺀다**. 빈 네모를 보여주지 않는다.

## 3. 섹션별 카피 틀 (리치코드 원문이 모델)

| 섹션 | 틀 | 리치코드 |

| 히어로 story | 상태 → 포기 → 찾은 답 한 줄(액센트) | …찾은 답은 하나였습니다. 노력이 아니라, 무의식이 문제였습니다. |

## 4. 숫자·후기·보장
- 가격 사다리(1차 종료 / 2차 종료 / 3차 현재 / 4차 정가 전환 예정)는 **실제로 그렇게 팔았을 때만**. 처음 파는 책은 사다리 없이 "첫 독자 가격" 배지 + 정가 취소선만.
- 보장 문구("후기가 조작일 시 100% 환불 / 천만원")는 사용자가 쓸지 말지와 금액을 정한다.
- 임시 후기 쓰는 법: 6개. 02_market 의 고객 언어(결핍 문장)를 "전 → 후" 로 묶어 3~4문장씩. 연령·직업·상황을 여섯 개가 서로 다르게(20대 취준생, 30대 직장인, 40대 자영업, 육아 중인 엄마 등). 출처는 "30대 직장인, 서울" 식의 연령·직업·지역만. 실명·수치 성과("한 달에 500만 원")는 넣지 않는다.
- 연구 인용은 `02_research.md` 에 출처가 있는 것만, 학자 이름 + 한 줄. 수치 비율(10%/90%)은 널리 인용되는 것일 때만 쓰고, 아니면 막대를 뺀다.
- "100% 보장", "완치", "1위", "최고" 같은 광고심의 위반 표현 금지. "~할 수 있습니다", "~를 담았습니다" 로.

## 5. 브랜드·익명
- 저자가 병조쌤 본인이 아닌 책: 비라스·비제이라이프스쿨·리치코드·병조쌤 CTA 금지.
- 익명 브랜드(예: 대화설계): 저자 실명·실제 상호를 어디에도 쓰지 않는다. 푸터는 브랜드명만.
- 대화법 책에 "27년 모솔" 같은 사실이 아닌 수식 금지. 저자 설정은 intake 의 사실만.

## 6. 전달 전 자기 검수 (카피)
- h1 ≤ 3줄, 각 줄 ≤ 10자인가
- 섹션마다 h2 하나, 액센트 한 줄인가
- 자리표시자 목록을 뽑았는가 (빌더 --check)
- 성과·수치는 전부 출처가 있는가. 임시 후기는 sample:true 가 붙어 있는가
- 같은 의도의 버튼 문구가 하나로 통일됐는가
- 이모지·→·가운뎃점·em-dash·대문자 라벨이 없는가
