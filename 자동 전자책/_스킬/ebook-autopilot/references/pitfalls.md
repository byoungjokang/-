# 알려진 함정 + 브랜드 규칙 (다시 겪지 말 것)

claude.ai 세션에서 디자인 스킬을 만들며 반복해서 겪은 것들. 빌더(`scripts/build_ebook.js`)는 이미 전부 반영했다. **빌더를 고칠 때 아래를 깨지 않는지 확인한다.**

## 디자인 함정 5

1. **풀블리드(페이지 전체 배경) + 페이지별 푸터 조합 금지.** 워드 푸터는 본문과 별도 영역이라 표 트릭으로 배경을 칠해도 푸터엔 색이 안 닿는다 → 페이지 사이·표지 하단에 흰 띠. 빌더는 배경색을 `Document.background` 로 문서 전체에 딱 한 번만 칠하고, 표 트릭을 쓰지 않는다. 푸터는 가운데 쪽번호 하나 (풀블리드가 없으니 흰 띠가 생기지 않는다).
2. **`spacing.line` 에는 반드시 `lineRule: LineRuleType.AUTO`.** 빠뜨리면 170% 로 의도한 줄간격이 100% 로 렌더링된다. 기준: 240 = 100%, 408 = 170%. **`line` 값은 twip 이 아니다** — 1150 같은 값을 넣으면 4.8줄 간격이 된다 (이번 빌더 첫 빌드에서 실제로 겪음 → 표지가 2페이지로 넘침).
3. **챕터 오프너 페이지 금지.** 챕터마다 거의 빈 페이지가 반복되어 "여백이 심하다" 피드백. 챕터 제목은 본문 페이지 맨 위 헤더 (`pageBreakBefore` 문단). 파트 디바이더는 책당 2~4장뿐이라 허용하되 `--no-part-dividers` 로 끌 수 있다.
4. **색 블록은 여백 안에서 문단 shading 으로.** 빌더의 `shaded()` 는 shading + 같은 색 테두리(`border.space`) 로 안쪽 여백을 만든다. 연속 문단의 테두리 설정이 같으면 워드/리브레가 한 박스로 합친다. **블록 안 문단마다 indent 를 다르게 주면 톱니(notch)가 생긴다** — 인셋은 indent 가 아니라 border space 로.
5. **리스트 → 산문 변환 시 번호 접두어 벗기기.** 원문에 "1) 2) 3)" 이 박혀 있으면 콤마로 이어붙였을 때 그대로 남는다. `validate_book.js` 가 경고한다.

## 빌더 검증 방법

```
node build_ebook.js ../references/sample-book.json out.docx --template 02   # 샘플 원고 5챕터
node to_pdf.js out.docx --preview        # out.pdf + out_sheet.png
```
`_sheet.png` 에서 확인: 표지 1페이지 / 차례 쪽번호 / 파트 블록이 한 페이지 안에 / 빈 페이지 없음 / 챕터 제목 아래 간격 정상.
어두운 템플릿(02, 09)과 흰 템플릿(03, 08) 하나씩은 꼭 본다 — 블록 색 대비가 다르다.

## 브랜드 규칙 (반드시)

- 스킬 description·로직·기본값에 "리치코드/비라스/비제이라이프스쿨" 하드코딩 금지. 저자·브랜드는 intake 에서 채운다.
- `bj-essay-voice` 와 그 CTA 문구("병조쌤이 직접 운영하는 단톡방 입장하기")는 **병조쌤 본인 책에만**. 타 저자는 `[저자 커뮤니티 링크]`.
- "비라스"/"비제이라이프스쿨"은 병조쌤 본인 책에도 넣지 않는다 (코어 독존감 작업 시 명시적 지시).
- `validate_book.js` 가 `meta.authorIsBj` 를 보고 검사한다. 이 플래그를 거짓으로 두고 우회하지 않는다.

## 민감 주제 규칙 (폭식증 책에서 확립)

- 칼로리·체중·식단 수치 미포함, 결과 보장 문구("요요 없는") 배제
- 전문가 연계 챕터 필수
- 고백 챕터는 실명이 아닌 구성 사례
- 도발 자극 제외 (ebook-outline 의 도발 게이트)

## 미결 (이 생성기가 정한 기본값)

- 디자인 톤: 확정 안 됨 → 생성기는 **흰 종이 + 여백 안 색 블록** 방식(흑백 심플 프로토타입 구조)에 10선 팔레트를 얹는 절충안. 템플릿 번호로 팔레트만 바꾼다.
- 폰트: Pretendard Variable / Noto Serif KR / Gowun Batang 지정. 미설치 PC 에서는 대체됨. PDF 는 빌드한 PC 의 폰트로 고정되므로 **PDF 를 최종 납품본으로** 권장.
