# 저자 문체 추출 절차 — voice-extract → 00_voice.md

intake D 에서 (b) 를 고르고 저자 본인 글 2~3편(각 500자 이상)을 준 경우에만 실행한다. 결과물 `00_voice.md` 는 `voice-default.md` 와 같은 목차를 가지되, 각 항목을 저자 글에서 뽑은 **실제 예문**으로 채운다. 저자 본인 글이므로 표현을 그대로 재사용해도 된다.

## 절차

1. 샘플 글을 전부 읽고 다음을 표로 정리한다.
   | 항목 | 관찰 | 예문 (원문 그대로) |
   |---|---|---|
   | 종결어미 | 존댓말/해라체, ~습니다/~요 비율 | |
   | 문장 길이 | 평균 글자 수, 한 줄 문단 사용 여부 | |
   | 오프닝 습관 | 질문/장면/인용/선언 중 무엇으로 여나 | |
   | 감정 격발 어휘 | 실제로 쓴 강한 표현 (있으면) → 수위 판정 | |
   | 자주 쓰는 연결어·추임새 | "근데", "사실", "솔직히", "그리고......" 등 | |
   | 비유 스타일 | 일상 사물/스포츠/동물/돈 등 어느 영역에서 끌어오나 | |
   | 독자 호칭 | 당신/여러분/너/없음 | |
   | 숫자 사용 | 구체 수치를 쓰는가 | |
   | 닫는 습관 | 선언/질문/여운/CTA | |
   | 금기 | 샘플에서 한 번도 안 쓰는 것 (예: 이모지, 느낌표, 영어) | |

2. `voice-default.md` 를 복사해 `00_voice.md` 를 만들고, 각 섹션의 규칙을 위 표로 **덮어쓴다**. 저자 글에 없는 습관을 지어내지 않는다 — 관찰 안 된 항목은 default 규칙을 유지한다고 명시.

3. 트랙 시스템(서사/방법)과 정반합 오프닝은 저자 글에 없어도 유지한다 — 이건 문체가 아니라 전자책 구조 규칙이다. 다만 오프닝 방식은 저자 습관에 맞게 조정 (질문으로 여는 저자면 "통념을 질문 형태로 인용").

4. 마지막에 **테스트 문단** 하나를 쓴다: 저자 원료(intake C1 밑바닥 장면)를 `00_voice.md` 규칙으로 300자 산문으로 써서 파일 끝에 붙이고, 사용자에게 "본인 글처럼 읽히는가" 확인받는다. 아니라고 하면 어느 부분이 다른지 듣고 표를 고친다.

## 산출 형식

```
# 00_voice.md — <저자명> 문체 가이드
(추출 근거: 샘플 N편, 총 M자)

## 관찰표
## 0. 트랙
## 1. 오프닝
## 2. 문장 리듬 (예문 3개)
## 3. 숫자
## 4. 어휘 수위: 강/중/약 — 근거 예문
## 5. CTA
## 6. 하지 않는 것 (샘플 기준 금기 + default 금기)
## 테스트 문단
```
