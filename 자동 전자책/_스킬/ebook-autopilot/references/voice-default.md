# 기본 문체 가이드 (타 저자용) — voice-default

병조쌤 본인이 아닌 저자의 책에 쓰는 기본 문체다. `bj-essay-voice` 의 **구조**(트랙 시스템·정반합 오프닝·숫자 신뢰·여운 닫기)는 그대로 가져오되, 병조쌤 고유의 표현·비유·거친 어휘·브랜드는 전부 뺐다. 저자 샘플 글이 있으면 이 파일 대신 `voice-extract.md` 로 만든 `00_voice.md` 를 쓴다.

## 핵심 정체성

**직접 겪어본 사람이 독자 옆자리에 앉아 말한다.** 상담사처럼 다독이지 않고, 강사처럼 가르치지 않는다. "나도 그랬다"에서 시작해서 "그래서 이렇게 했다"로 간다. 존댓말이 기본(`~습니다` / `~요` 혼용). 해라체는 intake D 에서 고른 경우만.

## 0. 트랙 먼저 정한다 (챕터마다)

- **서사 트랙** — 고백·진단·전환·본질·에필로그. 순수 산문. 번호 리스트·박스·체크리스트를 쓰지 않는다. 대비는 표가 아니라 대사로 ("예전의 저라면 이렇게 생각했을 겁니다. '…' 그런데 지금은 이렇게 생각합니다. '…'").
- **방법 트랙** — 실전 방법을 가르치는 챕터만 (책 전체 3~5개). 이름 붙은 기법, 준비물, 1·2·3 절차 허용. 단 **여는 문장은 장면, 닫는 문장은 여운**. 절차로 시작하거나 절차로 끝나면 매뉴얼이다.

한 챕터 안에서 두 트랙을 섞지 않는다.

## 1. 공통 오프닝 — 정반합

1. 세상이 흔히 하는 말을 따옴표로 먼저 건다. ("꾸준히 하면 됩니다.")
2. 그게 왜 안 통하는지, 직접 해본 사람으로서 반박한다.
3. 세 문장 안에 인용 → 반박 → "그 말을 한 사람은 정말 겪어봤을까"까지.

이 오프닝이 `lead` 블록이다.

## 2. 문장 리듬

- 짧은 문장. 한 문단 3~5줄. 한 줄짜리 문단을 가끔 섞어 리듬을 만든다.
- 독자에게 직접 묻는다. "당신은 어떻습니까?" "그때 뭐라고 했을 것 같습니까?"
- 자문자답. "왜 그럴까요?" 던지고 스스로 답한다.
- 감정을 쭉 서술하다가 한 번에 압축: "정리하면 이겁니다. …" (`point` 블록 자리)
- 비유는 한 챕터에 하나, 길게. 짧은 비유 여러 개보다 긴 비유 하나가 남는다.

## 3. 신뢰는 숫자로

"많이", "오래", "정말" 대신 intake C 의 실제 수치. "3년", "47번", "월 180만 원", "12kg". **intake 에 없는 숫자는 만들지 않는다.** 연구 인용은 `02_research.md` 에 출처가 있는 것만.

## 4. 어휘 수위 (intake D)

- 강: 감정 격발 지점에 거친 표현 허용 (저자 샘플에 실제로 있을 때만)
- 중 (기본): "형편없는", "말도 안 되는", "지긋지긋한" 수준
- 약: 감탄사·반복 강조로 대체 ("정말, 정말 화가 났습니다")

수위와 무관하게: 문단마다 쓰지 않는다. 논리를 다 쌓고 터지는 지점 한두 번.

## 5. CTA

intake A 의 문구만 쓴다. 없으면 `[저자 커뮤니티 링크]` 그대로 둔다. 빈도는 meta.ctaMode (절제: 프롤로그·에필로그 / 반복: 매 챕터 끝).

## 6. 하지 않는 것

- "힘드셨겠어요", "당신 잘못이 아니에요"로 열지 않는다.
- "여러분", "~하시기 바랍니다", "명심하세요", "~해보는 건 어떨까요?" 금지.
- "노력하세요", "긍정적으로 생각하세요" 같은 두루뭉술한 조언 금지 — 방법 트랙이면 이름과 절차, 서사 트랙이면 구체적 장면.
- 서사 트랙에서 "첫째, 둘째, 셋째" 금지.
- 책 밖의 브랜드·인물 이름(병조쌤/비라스/비제이라이프스쿨/리치코드 포함) 금지. 사례는 "코칭에서 만난 한 분은" 식으로.
- 없는 연구, 없는 숫자, 없는 사례를 만들지 않는다. 원료가 부족하면 `[원료 필요: C7 타인 사례]` 라고 남기고 사용자에게 묻는다.
