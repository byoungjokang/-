# EBOOK DESIGN MASTER GUIDE — 30 STYLE PRESETS

> 목적: 전자책 원고의 주제·독자·감정·정보 밀도·신뢰성 요구·이미지 필요도·행동 유도 정도를 분석해,
> 30개 프리셋 중 최적 스타일을 선택하거나 2개 스타일을 혼합하여
> 표지·목차·PART·CHAPTER·본문·인용문·체크리스트·표·도식까지 일관되게 설계한다.

---

# 0. 공통 디자인 시스템

## 기본 원칙
- 기본 판형: A5 세로형 148 × 210mm
- 상단 여백 16~22mm, 하단 16~20mm, 좌우 16~20mm
- 본문 폭: 페이지 폭의 약 70~76%
- 본문 10.5~11.5pt, 행간 165~180%
- 정보 위계: `BOOK TITLE → PART → CHAPTER → SECTION → BODY → CAPTION`
- 한 페이지에 강한 시각 요소는 1개
- 표지보다 본문 완성도를 우선
- 프리셋은 색상 템플릿이 아니라 **편집 문법**
- 한 권 안에서 컬러·타이포·카드·인용문·이미지 언어를 반복해 일관성을 만든다.

## 공통 콘텐츠 컴포넌트
`KEY MESSAGE` / `QUOTE` / `CASE` / `CHECKLIST` / `STEP` / `BEFORE & AFTER` /
`DO & DON'T` / `SCRIPT` / `RESEARCH` / `SUMMARY` / `TIP` / `WARNING` /
`FRAMEWORK` / `WORKSHEET` / `KEY NUMBER`

## 자동 스타일 선택 기준
1. 주제
2. 타깃 독자
3. 핵심 감정
4. 정보 밀도
5. 신뢰성 요구
6. 이미지 필요도
7. 행동 유도 정도

## 혼합 규칙
- 기본: 메인 프리셋 70% + 보조 프리셋 30%
- 메인: 전체 컬러·타이포·표지 톤 결정
- 보조: 카드·표·도식·인용문 스타일 보완
- 3개 이상 혼합 금지
- 이미지 스타일과 타이포 시스템은 각 2종 이하

# EB01 — Warm Parenting Editorial
**성격:** 따뜻하지만 유치하지 않은 프리미엄 부모교육 편집 스타일  
**추천 주제:** 육아, 부모교육, 감정대화, 훈육, 아이 심리, 관계 회복  
**타깃:** 영유아·초등 자녀를 둔 부모  
**핵심 감정:** 공감, 안도, 따뜻함, 회복, 신뢰  
**키워드:** Warm / Calm / Emotional / Premium

### 컬러
- Background `#FBF5EC`
- Section `#F4E6D6`
- Primary `#D9775A`
- Secondary `#C9694A`
- Text `#3D2B24`
- Sub `#8C766B`
- Line `#E4B9A4`

### 타이포
- Book Title 30~38pt Bold Serif/Sans
- Part 12~14pt, 자간 넓게
- Chapter 22~27pt Bold
- Body 10.5~11.5pt
- Quote 13~16pt

### 표지
크림 배경, 제목 중심, 하단 40~50% 부모·아이 감성 일러스트. 제목과 그림 영역을 분리한다.

### 목차
`CONTENTS / 차례` 상단 배치. PART와 CHAPTER를 크기·자간·색으로 구분한다.

### PART
한 페이지 전체 사용. 큰 번호, 짧은 한 문장, 작은 감성 일러스트 또는 넓은 여백.

### 본문
긴 글을 편안하게 읽도록 여백을 충분히 두며, 2~3페이지마다 강조 컴포넌트 1개.

### 추천 컴포넌트
SCRIPT / CASE / CHECKLIST / RESEARCH / KEY MESSAGE

### 이미지
soft parenting cartoon, warm indoor lighting, cream/beige palette, gentle expressive faces. 같은 책에서는 캐릭터 외형 유지.

### 피해야 할 것
원색, 유아용 캐릭터풍, 키즈카페 느낌, 모든 페이지 일러스트, 둥근 카드 남발.

### 자동 선택
육아 + 부모 감정 + 관계 회복 + 공감 중심.

# 콘텐츠 컴포넌트 사용 기준
- **KEY MESSAGE:** 한 장 핵심 주장, 1~3문장
- **QUOTE:** 인용문, 본문보다 20~40% 크게
- **CASE:** 사례, 배경색 3~6% 변화
- **CHECKLIST:** 3~7개, 체크 아이콘만 포인트색
- **STEP:** 1~5단계, 숫자를 시각 앵커로
- **BEFORE / AFTER:** 비교형 실용서
- **SCRIPT:** 대화·카피·실전 문장
- **RESEARCH:** 연구 근거, 출처는 작게
- **WARNING:** 법률·건강·금융 주의
- **FRAMEWORK:** 구조 설명, 선과 화살표 최소화
- **WORKSHEET:** 실제 작성 가능한 여백
- **KEY NUMBER:** 숫자를 제목보다 크게

# 페이지 리듬
- 본문 2~3페이지 → 강조 페이지 1페이지
- PART 시작 → 여백 많은 페이지
- CHAPTER 시작 → 강한 메시지 1개
- 긴 설명 → CASE 또는 QUOTE
- 실용서 → 3~5페이지마다 CHECKLIST
- 데이터 중심 → 2~3페이지마다 표·도식
- 에세이 → 4~6페이지마다 풀페이지 문장/이미지

# 시리즈 제작 규칙
- 기존 책의 Primary Color 유지
- 동일 타이포 시스템 유지
- 표지 레이아웃만 변화
- 같은 캐릭터 또는 이미지 언어 유지
- PART·CHAPTER 규칙 동일
- 보조 프리셋만 20~30% 변화

예:
- 1권 `EB01 70% + EB03 30%`
- 2권 `EB01 70% + EB10 30%`
- 3권 `EB01 70% + EB04 30%`

# 최종 품질 체크리스트
- 모바일 썸네일에서도 제목이 읽히는가
- PART/CHAPTER 위계가 명확한가
- 글이 빽빽하지 않은가
- 2~3페이지마다 리듬 변화가 있는가
- 강조 방식이 2~3종 이하인가
- 메인 포인트 컬러가 1개인가
- 이미지 스타일이 한 권에서 일관적인가
- 인물 캐릭터가 바뀌지 않는가
- 핵심 메시지가 시각적으로 보이는가
- A5 출력과 모바일 열람이 모두 가능한가
- PDF에서 글자·이미지 깨짐이 없는가
- 판매용 상품 수준으로 보이는가
