# 시장 검증 7채널 + 고객 언어 수집 → 10주제 표 (02 리서치 앞단, 2026-09-20 추가)

02 리서치(`ebook-topic-research`)의 학술·해외 심화에 들어가기 **전에**, 주제가 실제로 팔리는지와 고객이 그 문제를 무슨 말로 부르는지를 먼저 확인한다. 이 절차의 산출물은 `02_market.md` 이며, 03 목차의 제목 후보와 상세페이지 카피의 원료가 된다.

입력: `01_onething.md` 의 원씽 문장 + "1-3 리서치에 넘길 키워드 5~8개". 원씽이 아직 없고 넓은 주제만 있으면(예: "찐따 십선비 연애대화법") 그 주제어로 시작하고, 이 절차의 결과로 10주제 표를 만들어 01 주제 쪼개기의 입력으로 되돌린다.

## 1. 채널별 절차 (7채널 + 보조 3)

같은 키워드 5~8개를 채널마다 돌린다. 채널마다 **"수요 있음"의 기준**이 다르다 — 숫자 하나로 판정하지 말고 표의 기준을 쓴다.

| 채널 | 도구 | 무엇을 모으나 | 수요 판정 기준 |
|---|---|---|---|
| 유튜브 | `YouTubeData-search_videos` (쿼터 소진 시 아래 우회) → `get_video_comments` (video_id, max_results 40, order relevance) | 조회수 상위 10~15개 영상 제목·조회수·채널 + 각 영상 댓글 40개 | 관련 영상 조회수 50만↑ 3개 이상, 상위 댓글 좋아요 500↑ 다수 |
| 브런치 | `NaverSearch-search_webkr` 에 `brunch.co.kr <키워드>` → 크롬 `navigate` + `get_page_text` 로 원문 | 연재 브런치북·매거진 제목, 당사자 고백 문장 | 같은 자기 규정어("모솔·찐따·선비")를 쓰는 연재가 3편 이상 |
| 인스타 | 태그 페이지는 로그인 벽으로 직접 수집이 안 된다. 유튜브 채널의 인스타 링크(댓글 고정)로 계정 파악 + `search_webkr` 로 틱톡 discover 조회수 | 어떤 크리에이터가 이 주제로 팔로워를 모으는지 | 간접 검증으로 표기. 단독으로 ★ 판정 근거로 쓰지 않는다 |
| 메타 광고 | `ads_library_search` (countries KR, ad_active_status ALL, limit 30, client_conversation_id 20자) 를 키워드 5개 이상 | 페이지명·랜딩 제목·건수. **'기회를 파는 광고'(앱·파티)와 '능력을 파는 광고'(강의·전자책·코칭)를 나눠 센다** | 능력 광고가 1~5건이면 빈틈, 0건이면 검색·광고로 자각시켜야 하는 시장, 30건↑이면 포화 |
| 인프런 | `search_webkr` `inflearn <키워드>` | 강의 존재 여부 | 자기계발·관계 주제는 대부분 없음 → "채널 부적합"으로 기록하고 넘어간다 |
| 클래스101 | `search_webkr` `class101 <키워드>` → 크롬으로 상세 | 클래스명·강사·타깃 문구 | 타깃 문구에 우리 원씽의 '대상·상황'이 그대로 있으면 경쟁, 없으면 빈틈 |
| 탈잉 | `search_webkr` `taling <키워드>` | PDF·클래스명·가격 | 멘트집·PDF가 많으면 그 하위 주제는 포화로 표기 |
| 크몽(보조) | `search_webkr` `kmong <키워드>` → 크롬으로 상세 | 상품 설명의 **타깃 문구 원문**, 가격대, 리뷰 수 | 고가 코칭이 팔리면 전자책 가격 저항 낮음 |

### 유튜브 검색 쿼터 우회 (하루 한도 자주 소진됨)
크롬 `navigate` → `https://www.youtube.com/results?search_query=<URL인코딩>&sp=CAMSAhAB` (조회수순) → `wait 3~4초` → `javascript_tool`:
```js
[...document.querySelectorAll('ytd-video-renderer')].slice(0,15).map(v=>{const a=v.querySelector('#video-title');const id=(a?.href||'').match(/v=([\w-]{11})/)?.[1];return [id,a?.textContent.trim().slice(0,60),(v.querySelector('#metadata-line')?.textContent.match(/조회수 [\d.,만천억]+회/)||[''])[0],v.querySelector('#channel-name #text')?.textContent.trim()].join(' | ')}).join('\n')
```
빈 결과나 `[BLOCKED…]` 가 나오면 같은 페이지를 한 번 더 돌린다. 댓글 API(`get_video_comments`)는 검색 쿼터와 별개라 계속 쓸 수 있다. 댓글이 꺼진 영상은 건너뛴다.

## 2. 고객 언어 수집 규칙

- 댓글·카페 글·상품 타깃 문구를 **원문 그대로** 옮기고 좋아요 수(👍)·출처(영상 ID 또는 URL)를 붙인다. 다듬지 않는다 — 다듬는 순간 고객 언어가 아니라 내 언어가 된다.
- 영상당 댓글 40개 중 **문제를 자기 말로 부르는 댓글**만 남긴다(응원·드립·연예인 언급 제외). 보통 영상당 3~8개.
- 모은 문장을 **결핍 클러스터 5~7개**로 묶는다(예: 얼어붙음/면접 모드 · 노잼/선비 · 착함의 함정 · 애씀/절박 · 자기효능감). 클러스터 이름은 고객 말에서 딴다.
- 각 클러스터에서 **최다 좋아요 문장 1개**를 표시한다 — 이게 그 장의 제목 후보이자 상세페이지 첫 줄이다.
- 통념(세상이 흔히 주는 답)도 같이 적는다("애쓰지 마라", "자신감 가져라"). 이건 03 목차의 정반합 과녁이다. 통념이 이미 대중 상식이면(조회수 100만↑ 영상이 말하는 것) 그걸 반복하는 주제는 ★을 낮춘다.

## 3. 출력 `02_market.md`

```
# <주제> — 7채널 시장 검증 (YYYY-MM-DD)
수집 채널·도구 한 줄

## 1. 채널별 수요 검증  (표: 채널 | 검증 결과(숫자·제목) | 판정 ★)
종합 한 문단: 수요가 교차 검증된 채널 수 / 경쟁이 몰린 곳 / 빈틈 한 문장

## 2. 고객의 언어  (클러스터 A~F, 각 문장에 👍·출처)

## 3. 통합 인사이트 (5~6줄: 원인 재진단, 통념, 빈틈)

## 4. 10개 주제 제안  (아래 표 형식 고정)
| 순위 | 주제명 | 해결하는 문제 | 핵심 약속 | 구매 근거 | 예상 목차 스케치 |
추천 한 줄: 1위를 원씽으로, 흡수할 순위, 범프딜 후보

## 5. 출처 목록 (영상 ID · 브런치 URL · 카페 글 번호 · 광고 검색어·건수 · 데이터랩 기간)
```

### 10주제 표 작성 규칙
- **주제명**: `ebook-title-monetize` 의 수익화 공식([타깃·조건]+[제약]+[숫자 결과]+[결과 동사]+[방법 명사])으로 쓴다. 숫자는 절차 숫자(횟수·기간·개수)나 저자 실제값만, 보장어 금지. 에세이형 훅(질문형)은 주제명이 아니라 부제·광고 카피 자리다. 명사형 밋밋한 제목 금지.
- **해결하는 문제**: 고객 언어 클러스터에서 2~3문장. 증상 → 왜 지금 방법이 안 먹히는지.
- **핵심 약속**: 기간·횟수·개수가 들어간 한 문장("세 번의 만남 안에", "문장 7개").
- **구매 근거**: ★ 5단계 + 근거 숫자 나열. ★ 기준 — ★★★★★ 3채널 이상 교차 + 최다 좋아요 1,000↑ + 경쟁 빈틈 / ★★★★☆ 2채널 교차 / ★★★☆☆ 1채널 강함 또는 경쟁 포화 / ★★☆☆☆ 이하는 표에 넣지 않는다.
- **예상 목차 스케치**: 프롤로그 / PART 또는 01~06 / 에필로그 한 줄. 이름 붙은 기법이 있으면 작은따옴표.
- 순위는 ★ → 최다 좋아요 → 경쟁 빈틈 순. 마지막에 **추천 한 줄**: 1위를 원씽으로 잡고 어떤 순위를 PART로 흡수할지, 범프딜 후보는 무엇인지.

## 4. 승인 게이트
`02_market.md` 저장 → 10주제 표를 채팅에 그대로 보여준다(표 형식 유지) → 사용자가 순위 하나를 고르거나 합치면 그 결과를 `01_onething.md` 원씽으로 확정(또는 갱신)하고 `status.js --set 01 approved` 후 02 심화 리서치로 간다. intake F 가 "생략"이면 이 절차도 건너뛴다.

## 5. 함정
- 여성 타깃 영상(예: "여자 모태솔로 특징")의 댓글은 남성 타깃 책의 고객 언어가 아니다. 영상의 시청자 성별을 댓글로 확인하고 섞지 않는다.
- 픽고·띱 같은 드라마형 채널은 조회수는 크지만 댓글이 배우 얘기다 — 문제를 부르는 댓글만 골라 쓴다.
- 메타 광고 `estimated_total_count` 는 검색어에 따라 앱 광고가 섞인다. 페이지명을 보고 '기회/능력'으로 반드시 나눈다.
- 좋아요 수·건수는 수집일 기준이다. 파일 첫 줄에 날짜를 남긴다.
