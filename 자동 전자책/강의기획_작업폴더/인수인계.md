## 3. PPT 다시 만드는 법
```
cd build
npm install            # pptxgenjs 4.0.1
node build.js 무료라이브_PPT.pptx ./slides.js
```
- `slides.js` = 내용(장 하나 = 객체 하나). `k`는 레이아웃 종류, `see`는 화면에 띄울 것, `say`는 말로 할 것(발표자 노트로 들어감).
- `build.js` = 디자인. 확정 스타일은 **캔바 샘플 ① 미니멀 화이트 + 진한 레드(B0000C)**, 왼쪽 정렬 큰 검정 글씨, 강조 박스는 레드 채움 + 흰 글씨.
- 글꼴: Pretendard / Pretendard Black (PC에 설치 필요, `../라이브PPT/폰트_Pretendard/`).
- 레이아웃 종류: line, q, big, blind, img(자료 자리), imgs, pic, pics, list, two, flow, table, eq, sum, bars, phone, day, cards, map, bubbles, shelf, coaster, donut, kpi, chart, inbox, quote.
- 사진 넣기: 장 객체에 `photo: "kang"`처럼 `img/` 안 파일 이름(확장자 빼고)을 주면 오른쪽에 들어감. 새 이미지는 `img/meta.json`에 [가로, 세로] 크기도 추가해야 함.

- 3~11구간 내용 = 강사 본인 원고(10/12 PDF) 그대로.
- 메타 광고는 캡처 대신 **강의 중 PC 화면으로 직접 보여줌**.

## 7. 지켜야 할 것
- 배우 대역 "수강생 인터뷰" 쓰지 않기 (실제 수강생만).
- 해적판 PDF(Z-Library 등)로 문체 학습 금지.
- 증빙 없는 숫자는 화면에 띄우지 않기.
- 구매자 이름·이메일이 보이는 캡처(주문 목록 등)는 슬라이드에 쓰지 않기.
- 이 강의는 **다른 회사(어센드) 강의** — 비라스(블랙+레드) 브랜드 색·로고 넣지 않기.
- 사용자에게는 쉬운 한국어로 답하기.
